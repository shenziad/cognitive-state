# Research Question

更新：2026-10-03，v0.3 已有最小实现并完成两版预检；后续比较因门槛失败停止。见[第三轮报告](../results/analysis/research_cycle3_20261003/analysis.md)。

核心问题：在明确的任务延续范围、公共工具权限与恢复成本下，能否维护远小于历史的状态，同时保持继续完成任务的能力？

## 任务与接口条件

记当前目标为 G_t，预先约定的未来任务延续分布为 D，共同运行接口为 I（工具契约、权限、资源和可访问记忆）。提取过程为 `CS_t = f(H_t, G_t; D, I)`。提取器可以知道当前目标和任务类别，但不能看到随后实际抽取的未来测试问题、答案或隐藏评分。

D 的第一阶段范围是当前任务的续做、公开目标修改、诊断纠正和异步结果到达；不声称小状态能回答任意未来的历史追问。未来变化的支持范围和频率应在模型调用前冻结，不能看结果后修改。

最小状态依赖 I：免费恢复全部历史与恢复需要付出成本，会产生不同问题。每个条件实际读取的共同说明、用户消息、工具输出和恢复材料都计入输入及成本。

## 行为充分性

比较同一未来延续上的任务成功、约束遵守、必要工具操作和完成证据，而不是输出文本。Full Context 可能失败，因此同时报告相对 Full 的变化和独立任务标准下的绝对表现。

可研究的目标是：在预先规定的可接受性能损失 ε 与绝对质量门槛下，寻找活动表示最小的可行点。ε、质量门槛、样本量和统计方法必须在正式实验前确定。单轮结果或两条件都失败不能证明行为等价。

同时另报总输入/输出 Token、缓存输入、更新/恢复调用、延迟及有依据的金额。状态短、总 Token 少、实际费用低是不同目标，不能互相代替。

## 可区分的研究问题

1. 哪些目标、证据、执行阶段和未决义务对后续完成任务有必要作用？
2. 来源、有效性与失效传播规则是否减少无依据确认、旧目标复活和重复操作？
3. 相同可用材料与资源下，G/W/F 是否优于有竞争力的任务导向摘要？
4. 候选行动是否有益，还是会固化错误计划？
5. 增量更新与从同一可用材料重建相比，何时更容易保留或纠正错误？
6. 排除格式/编码失败后，缩短语义状态会怎样影响行为？端到端系统又付出了多少恢复成本？
