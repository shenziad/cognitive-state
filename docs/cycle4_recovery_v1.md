## 完整恢复顺序与唯一恢复次数

1. 从头运行全部 96 个预检组合，使用原冻结分配顺序。不得依据旧轮成绩/语义注释修改提示或删除任务。
2. 依据公开来源审阅全部 72 份最终压缩表示（提取失败标 not_observed），再回放、生成 gate。原始旧轮的语义错误照常另报，不参与恢复轮分母。
3. 仅在恢复预检完整且工程 gate 通过时，运行全部 56 个已知回归组合；完整审阅与回放后生成回归 gate。
4. 仅在回归 gate 通过时，运行全部 32 段四次交接；保持每个条件的实际世界和真实表示继承。

任一恢复阶段再次发生 API 中断、未知用量、设施错误或编码门槛未通过，停止本恢复计划，不进行第二次自动恢复。保留所有结果，继续完成不依赖该 gate 的任务设计与研究分析。正常行为失败和状态语义错误不触发重跑或调提示。
