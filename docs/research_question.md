# Research Question

在相同任务环境与未来任务分布下，能否以远小于完整历史的 Cognitive State 取代历史 Context，同时保持 Agent 继续行动的能力？

## 操作化问题

1. 哪些目标、世界认识与认知边界信息，对未来任务结果具有因果相关性？
2. 在相同 Token 预算下，结构化 Cognitive State 是否优于普通摘要？
3. 状态缩短到什么程度会明显损害任务成功、工具选择或决策一致性？
4. 状态提取错误、过时信念和错误假设会如何传播到后续行动？

比较的单位是同一历史的未来续做任务，不是历史内容的重构质量。`Behavior` 需由可观察的任务结果、工具调用和决策轨迹近似测量；不同任务可使用不同评分器，但应在实验前固定评分规则。
